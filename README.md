# haircut-data
This is a project from a course I took in Fall, 2024 on statistical machine learning. I used portions from the haircut30k dataset, https://github.com/sarkrui/Hairstyle60k, to train a convolutional neural network as a feature extractor for further training/testing support vector machines on the image data in order to classify hairstyles. I was not operating alongside a Github repo, so much of this code is jumbled and still needs to be sorted. Thought I would at least display my work and what was accomplished!
